# 홀덤 핸드·액션 어드바이저

Streamlit 기반의 개인용 텍사스 홀덤 승률 추정 및 팟 오즈 참고 도구입니다.

## 로컬 실행

Python 3.10 이상 권장:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 인터넷 배포

1. 이 폴더의 `app.py`, `requirements.txt`, `README.md`를 GitHub 저장소 최상위에 업로드합니다.
2. Streamlit Community Cloud에 로그인하고 저장소와 `app.py`를 선택해 배포합니다.
3. 배포가 끝나면 생성된 `*.streamlit.app` 주소로 접속합니다.

## 기능

- 시작 스택, BB/SB 자동 계산, 앤티 설정
- 10개 좌석과 상대 인원 설정
- 169개 시작 핸드 조합표와 실제 카드 무늬 선택
- 프리플랍 및 플랍/턴/리버 승률 추정
- 팟 금액, 콜 필요 금액, 콜 버튼으로 계산용 스택/팟 반영
- 블라인드·앤티 초기화 및 전체 초기화
- 용어와 시작 핸드 강도에 대한 개략 설명

## 주의

승률은 상대의 실제 핸드 범위를 알 수 없다고 가정해 상대 카드를 무작위로 뽑는 몬테카를로 추정치입니다. 상대의 베팅 범위, 포지션, 레이크, 토너먼트 ICM 등을 반영한 GTO 솔버가 아니며 실제 게임의 정답이나 수익을 보장하지 않습니다. 콜 버튼은 이 앱 안의 숫자만 갱신하고 실제 게임에는 연결되지 않습니다.
